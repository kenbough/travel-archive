# Japan map data

`japan.json` is copied from `jpn-atlas@1.0.2` and contains its simplified prefecture TopoJSON. It is stored locally so the JAPAN view does not depend on a large cross-origin download at runtime.

- Package: https://www.npmjs.com/package/jpn-atlas
- Source data: Geospatial Information Authority of Japan, Global Map Japan (2016)
